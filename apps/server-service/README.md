# Server Service

Server CRUD service for OpenHostMC

## Installation

```bash
npm install
```

## Running the app

```bash
# development
npm run start:dev

# production mode
npm run start:prod
```

## API Endpoints

- `GET /servers` - Get user's servers
- `GET /servers/:id` - Get server details
- `POST /servers` - Create new server
- `POST /servers/:id` - Update server
- `DELETE /servers/:id` - Delete server
